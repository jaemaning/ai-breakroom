Privacy Policy

시행일 Effective date: 2026-10-16

1. 누가 사용하나요 · Who uses this tool

AI Breakroom Uploader(이하 "도구")는 유튜브 채널 'AI 휴게실'의 운영자 1인만 사용하는 개인용 도구입니다. 운영자 외의 사용자 정보를 수집하지 않습니다.
AI Breakroom Uploader (the "Tool") is used only by the single operator of the "AI Breakroom" YouTube channel. It does not collect information from anyone else.

2. 접근하는 Google 사용자 데이터 · Google user data accessed

운영자가 허용한 권한(YouTube 데이터 API, youtube.force-ssl 범위)으로 운영자 본인 채널에 대해서만 다음을 합니다.

  • 영상 업로드, 제목·설명·공개 설정·예약 시각 등록 및 변경 · Upload videos and set title, description, privacy and schedule
  • 썸네일·자막 등록 · Set thumbnails and captions
  • 업로드한 영상의 처리·공개 상태와 채널 업로드 목록 조회(중복 업로드 방지용) · Read processing/privacy status and the channel's upload list (to prevent duplicate uploads)

Using the permission granted by the operator (YouTube Data API, youtube.force-ssl scope), the Tool performs only the actions above, and only on the operator's own channel.

3. 저장 · Storage

로그인 토큰(OAuth 토큰)은 운영자 컴퓨터의 로컬 파일에만 저장되며, 외부 서버로 보내지 않습니다. 업로드 기록(영상 ID, 처리 상태, 시각)은 운영자 컴퓨터의 로컬 데이터베이스에 저장됩니다.
OAuth tokens are stored only in a local file on the operator's computer and are never sent to any other server. Upload records (video IDs, status, timestamps) are kept in a local database on the operator's computer.

4. 공유·판매 · Sharing and sale

Google 사용자 데이터를 제3자에게 판매하거나 공유하지 않으며, 광고나 다른 목적으로 쓰지 않습니다.
Google user data is not sold or shared with third parties and is not used for advertising or any other purpose.

AI Breakroom Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. 보관 기간과 삭제 · Retention and deletion

토큰은 운영자가 권한을 취소하거나 파일을 삭제할 때까지 보관됩니다. 권한은 언제든 Google 계정 권한 설정에서 취소할 수 있습니다.
Tokens are kept until the operator revokes access or deletes the file. Access can be revoked at any time via Google Account permissions.
